Xspresso Platform Support Matrix

Purpose:
Track which platforms Xspresso supports, what each platform can do, and what limits apply.

Suggested Fields:
- Platform Name
- Supported Actions
- Upload Types
- Monitoring Supported
- Direct Upload Supported
- Notes / Rules
- Status (Planned / Beta / Live / Unsupported)

Example Structure:

Platform: TikTok
- Supported Actions: ad upload, monitoring, alerts, platform switch warnings
- Upload Types: image, short video, text caption
- Monitoring Supported: Yes
- Direct Upload Supported: Yes
- Notes / Rules: vertical format preferred; warn on policy or size issues
- Status: Live

General Rules:
- Every supported platform should have a visible status.
- If a platform is not supported, show a friendly note.
- If a platform needs special formatting, Xspresso should warn the user.
- If a user switches platforms, explain monitoring and credit changes clearly.
- If a platform is not listed, allow the user to request it.
- No promises unless support is verified.

Suggested User Copy:
- Choose from the platforms Xspresso supports.
- If your platform is not listed, tell Xspresso and we’ll see what we can do.
- Support may be limited by platform rules, sizes, or upload requirements.
