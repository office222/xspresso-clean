Xspresso image-generation setup

This runtime adds user-triggered OpenAI image generation to the campaign asset library. The image is saved as a campaign asset for review; generation does not publish an ad.

Environment:
- OPENAI_API_KEY: server-side secret; never expose it to browser code.
- OPENAI_IMAGE_MODEL: model name enabled for your OpenAI project.
- XSPRESSO_IMAGE_GENERATION_CREDIT_COST: required in production; set to 0 only for a deliberate no-charge development setup.
- Existing Meta/OAuth/SMTP settings remain as documented in the previous runtime setup.

Run with: node xspresso_openai_image_runtime_v1.js

The generated asset is attached to the campaign. If the campaign was approved, attaching a new creative returns it to review. Keep the OpenAI key and billing controls on the server. Tests use a mocked image response; no live image is generated by the test suite.
