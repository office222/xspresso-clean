Xspresso Quote 3 Board Shell - Responsive CSS Notes

Goal:
Keep the cup logo left of the name, allow the logo group to shrink together, and prevent stacking or overlap on smaller screens.

Recommended markup behavior:
- Use a 2-cell inline table for the logo area.
- Keep both images in the same row.
- Use white-space: nowrap on the logo cells.
- Use display:block on both images.
- Set max-width and height:auto on both images.

Suggested CSS:

.topbar {
  background: #ffffff;
  color: #111111;
}

.topbar img {
  display: block;
  height: auto;
  max-width: 100%;
}

.logo-wrap {
  white-space: nowrap;
}

.logo-cup {
  width: 70px;
  max-width: 70px;
  height: auto;
}

.logo-text {
  width: 100%;
  max-width: 560px;
  height: auto;
}

@media screen and (max-width: 640px) {
  .topbar {
    padding: 14px 16px !important;
  }

  .logo-cup {
    width: 52px !important;
    max-width: 52px !important;
  }

  .logo-text {
    max-width: 360px !important;
  }
}

@media screen and (max-width: 480px) {
  .logo-text {
    max-width: 260px !important;
  }

  .logo-cup {
    width: 44px !important;
    max-width: 44px !important;
  }
}

Implementation notes:
- Keep the header background white for cleaner rendering.
- Avoid dark top bars behind the logo because they make the image look muddy.
- If the text logo still feels too wide, resize the source image file itself.
- If the page is very narrow, preserve side-by-side layout first, then reduce image width.

Acceptance check:
- Cup remains left of the name.
- Logo stays inline on desktop and tablet.
- Logo scales down on smaller screens.
- No overlap, no stacking, no dark background showing through.
