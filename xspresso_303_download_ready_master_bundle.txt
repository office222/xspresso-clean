Xspresso Download-Ready Master Bundle

Purpose
This file is the compact source of truth for Xspresso. It consolidates the core product message, the V1 build scope, the board shell rules, the credits model, the monitoring rules, the dashboard rules, and the final file-organization guardrails.

1) Core Positioning
Xspresso is done-for-you marketing that gets responses, builds your list, follows up automatically, and lets the user stay in command.

Primary promise:
We do the work. You enjoy the benefits.

Support lines:
- Wake up your marketing.
- More responses. Less software chaos.
- Done-for-you marketing, fast.
- You stay in command. We do the work.

2) V1 Scope
Xspresso V1 should include:
- Campaign creation from product photo, URL, or offer details
- AI-generated headlines, hooks, ad copy, landing pages, carts, lead magnets, and follow-up emails
- Platform adaptation for destination-specific formats
- Lead capture and follow-up automation
- Monitoring for ads, CPC, stats, and alerts
- Credits / usage system
- Template / preset system
- Save, reuse, duplicate, export, import, and version history
- Dashboard and alerts
- Billing and subscription logic
- Platform switch warnings and per-ad monitoring choices

3) Campaign Flow
Input -> Research -> Draft -> Review -> Launch -> Monitor -> Improve

Inputs:
- Product photo
- URL
- Offer description
- Audience
- Goal
- Tone
- Platform(s)

Outputs:
- Headlines
- Hooks
- Ads
- Landing page
- Cart / checkout copy
- Lead magnet copy
- Follow-up emails
- Platform-specific versions

4) Credits and Usage Rule
All plans include every tool. Credits simply determine fair usage.

Usage examples:
- Landing page creation
- Extra social upload
- Ongoing ad monitoring
- Extra ad variations
- Extra follow-up sequences
- Rush switching / rush actions

Important rule:
If credits are being spent on something that is not producing returns, Xspresso should warn the user and recommend a better next step.

5) Monitoring / Alerts Rule
If an ad is underperforming:
- warn the user
- explain the issue
- suggest a fix
- offer regeneration before more credits are spent

Recommended alert copy:
- This ad is underperforming.
- Improve it before spending more credits monitoring an ad that is not performing.
- Xspresso can regenerate this ad with a new title, hook, or angle.

6) Platform Switch Rules
When switching platforms:
- show a big warning
- stop tracking on the old platform unless the user chooses to keep monitoring
- allow per-ad choices
- allow keep running, move to library, or keep monitoring for usage cost

Clear user-facing language:
- Warning: switching off [Platform Name] will stop Xspresso from tracking your ads there.
- Choose which ads you want Xspresso to keep tracking, or choose the option that fits your ads best.

Per-ad actions:
- Keep running
- Delete from [Platform Name] and move to library
- Keep Xspresso monitoring this ad
- I will track this myself

7) Lead Capture and Follow-Up
Xspresso should:
- collect leads
- tag them by campaign
- score engagement
- route them into lists
- send follow-up automatically

Lead states:
- new
- cold
- warm
- hot
- customer

8) Campaign Library / Reuse
Users may:
- save campaigns to library
- duplicate their own campaigns
- export / import their own work
- save templates
- restore previous versions

Important rule:
Only the user’s own work should be duplicated or reused.

9) Dashboard
The dashboard should show:
- active campaigns
- drafts
- alerts
- credits remaining
- monitored ads
- platform connections
- recent activity

Campaign cards should show:
- campaign name
- status
- platform
- CPC
- CTR
- conversions
- alerts
- quick actions

10) Billing / Subscription
Keep billing simple:
- clear plans
- clear credits
- clear renewal dates
- clear upgrade suggestions
- no bait-and-switch

Plan rule:
Every plan includes all tools. Higher plans simply provide more usage.

11) Founder Story
Use the founder story to explain why Xspresso exists:
- hard times
- poor decisions with ads
- lessons learned
- wanting to help people avoid wasting money and time
- wanting to help people build a lifestyle, not another job

Best emotional bridge:
That’s why I built Xspresso — a done-for-you marketing system designed to help people succeed faster, with less waste, less confusion, less guesswork, and less time spent alone in a room trying to figure it all out.

12) Hero Copy
Recommended hero:
Xspresso — Done-for-you marketing.
Done-for-you marketing that gets responses.
More responses. Less software chaos.

13) Board Shell / Header Rules
- White top bar
- Cup stays left of the name/logo
- Logo should shrink cleanly
- Avoid stacking / wrapping issues
- Keep it FrontPage-friendly and responsive

14) Board Shell / UI Rules
The reusable board shell should include:
- white header background
- inline cup + name/logo
- simple business-card-style intro block
- clear CTA buttons
- clean footer/support strip
- responsive behavior on smaller screens

CTA rules:
- Primary CTA: Try the Demo
- Secondary CTA: See Pricing
- Optional actions: Save Draft, Launch Now, Export, View Dashboard

15) Dashboard / Alerts / Monitoring
The dashboard should tell the user immediately:
- what is working
- what needs attention
- what to do next

Alerts should:
- be short
- be actionable
- explain the issue clearly
- suggest the next step
- offer regeneration when useful

16) File Organization Rule
Stop creating tiny one-off files.
Use a small set of master files instead:
- master bundle
- addenda
- one copy file
- one UI / HTML file
- one logic / code file
- one notes / library file
