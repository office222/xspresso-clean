--------------------------------------------------
MASTER BUILD PRINCIPLES
--------------------------------------------------

1. Done-for-you first.
2. The user stays in command.
3. All plans include every tool.
4. Credits determine fair usage.
5. No feature bait-and-switch.
6. Keep the product fast and simple.
7. Optimize for more responses, not more software clutter.
8. Monitor, warn, and recommend next actions.
9. Regenerate underperforming ads before spending more credits.
10. Let users save, reuse, and duplicate only their own work.

--------------------------------------------------
CORE PRODUCT SUMMARY
--------------------------------------------------

Xspresso is a done-for-you marketing system that helps users create campaigns faster, follow up automatically, monitor performance, and stay in command.
