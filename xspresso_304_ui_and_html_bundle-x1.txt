6) Reusable CTA Button Styles

Primary CTA:
- Try the Demo

Secondary CTA:
- See Pricing

Optional buttons:
- Save Draft
- Launch Now
- Export
- View Dashboard

Button rule:
- keep the primary action obvious
- keep the secondary action lighter
- do not overload the user with too many buttons

7) Responsive Behavior Notes
- Keep the white header background
- Keep the cup left of the name/logo
- Logo should shrink cleanly on smaller screens
- Prevent wrap / stacking issues
- Keep the board shell readable on mobile and tablet
- Keep the footer minimal and supportive

8) Core UI Message
Use these lines consistently:
- Xspresso — Done-for-you marketing
- Done-for-you marketing that gets responses.
- More responses. Less software chaos.
- You stay in command. We do the work.

9) Final UI Rule
If a UI element makes the page feel crowded, remove it.
If it helps the user understand what to do next, keep it.
If it repeats the same message without adding value, cut it.
