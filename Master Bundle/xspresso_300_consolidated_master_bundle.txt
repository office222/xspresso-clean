Xspresso Consolidated Master Bundle

Purpose:
This file replaces the many tiny working notes with one compact master reference. Use this as the main source of truth and stop creating small fragmented files.

1) Core Positioning
Xspresso is done-for-you marketing that gets responses, builds your list, follows up automatically, and lets the user stay in command.

Primary promise:
We do the work. You enjoy the benefits.

Support lines:
- Wake up your marketing.
- More responses. Less software chaos.
- Done-for-you marketing, fast.
- You stay in command, we do the work.

2) V1 Scope
Xspresso V1 should include:
- Campaign creation from product photo, URL, or offer details
- AI-generated headlines, hooks, ad copy, landing pages, carts, lead magnets, and follow-up emails
- Platform adaptation for destination-specific formats
- Lead capture and follow-up automation
- Monitoring for ads, CPC, stats, and alerts
- Credits / usage system
- Template / preset system
- Save, reuse, duplicate, export, import, and version history
- Dashboard and alerts
- Billing and subscription logic
- Platform switch warnings and per-ad monitoring choices

3) Credits and Usage Rule
All plans include every tool. Credits simply determine fair usage.

Usage examples:
- Landing page creation
- Extra social upload
- Ongoing ad monitoring
- Extra ad variations
- Extra follow-up sequences
- Rush switching / rush actions

Important rule:
If credits are being spent on something that is not producing returns, Xspresso should warn the user and recommend a better next step.

4) Monitoring / Alerts Rule
If an ad is underperforming:
- warn the user
- explain the issue
- suggest a fix
- offer regeneration before more credits are spent

Recommended alert copy:
- This ad is underperforming.
- Improve it before spending more credits monitoring an ad that is not performing.
- Xspresso can regenerate this ad with a new title, hook, or angle.

5) Platform Switch Rules
When switching platforms:
- show a big warning
- stop tracking on the old platform unless the user chooses to keep monitoring
- allow per-ad choices
- allow keep running, move to library, or keep monitoring for usage cost

Clear user-facing language:
- Warning: switching off [Platform Name] will stop Xspresso from tracking your ads there.
- Choose which ads you want Xspresso to keep tracking, or choose the option that fits your ads best.

Per-ad actions:
- Keep running
- Delete from [Platform Name] and move to library
- Keep Xspresso monitoring this ad
- I will track this myself

6) Campaign Flow
Input -> Research -> Draft -> Review -> Launch -> Monitor -> Improve

Inputs:
- Product photo
- URL
- Offer description
- Audience
- Goal
- Tone
- Platform(s)

Outputs:
- Headlines
- Hooks
- Ads
- Landing page
- Cart / checkout copy
- Lead magnet copy
- Follow-up emails
- Platform-specific versions

7) Lead Capture and Follow-Up
Xspresso should:
- collect leads
- tag them by campaign
- score engagement
- route them into lists
- send follow-up automatically

Lead states:
- new
- cold
- warm
- hot
- customer

8) Campaign Library / Reuse
Users may:
- save campaigns to library
- duplicate their own campaigns
- export / import their own work
- save templates
- restore previous versions

Important rule:
Only the user’s own work should be duplicated or reused.

9) Dashboard
The dashboard should show:
- active campaigns

- alerts
- credits remaining
- monitored ads
- platform connections
- recent activity

Campaign cards should show:
- campaign name
- status
- platform
- CPC
- CTR
- conversions
- alerts
- quick actions

10) Billing / Subscription
Keep billing simple:
- clear plans
- clear credits
- clear renewal dates
- clear upgrade suggestions
- no bait-and-switch

Plan rule:
Every plan includes all tools. Higher plans simply provide more usage.
